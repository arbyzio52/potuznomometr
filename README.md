# Потужнометр — Telegram Web App

Адаптивная мини-страница по мотивам макета и минимальный бот, который открывает её в Telegram. Показания генерируются случайно и служат только для развлечения.

## Структура проекта

- `website/` — статические файлы сайта, публикуемые на GitHub Pages.
- `bot/` — Telegram-бот и пример файла настроек.

## Запуск страницы локально

Откройте `website/index.html` в браузере. Кнопка проверки работает и без Telegram.

## Настройка и запуск бота

1. Создайте бота через BotFather и скопируйте токен.
2. Скопируйте `bot/.env.example` в `bot/.env`.
3. В `bot/.env` укажите `BOT_TOKEN` и HTTPS адрес сайта в `WEBAPP_URL`.
4. В PowerShell из корня проекта запустите `..\.venv\Scripts\python.exe bot.py` из папки `bot` либо `python bot/bot.py`.

Команда `/start` отправит кнопку открытия приложения. Не публикуйте `bot/.env` и не отправляйте токен другим людям.

## Публикация сайта

GitHub Actions автоматически публикует содержимое `website/` при каждом обновлении ветки `main`. В настройках репозитория в разделе **Settings → Pages** выберите **GitHub Actions** как источник публикации. Сайт должен быть доступен по HTTPS для Telegram Mini App.
